# ElvUI 9.09.10 — Sirus + DF UI

**ElvUI** — полная замена стандартного интерфейса World of Warcraft 3.3.5a. Аддон перерабатывает основные элементы интерфейса: фреймы персонажей и группы, панели действий, неймплейты, чат, сумки и другие элементы UI, позволяя настроить их внешний вид и расположение.

> [!IMPORTANT]
>
> ### Только Sirus + DF UI
>
> Эта версия ElvUI предназначена **ИСКЛЮЧИТЕЛЬНО для клиента Sirus с DF UI** и патч-листом **Interface 30300**.
>
> **DF UI является обязательным условием работы этой версии.**
>
> Обычный клиент Sirus **без DF UI не поддерживается** и отдельно не проверялся.

### Установка

Устанавливайте вместе папки:

* `ElvUI`
* `ElvUI_Libraries`
* `ElvUI_Options`

Все папки должны быть **одной версии**.

Полная история изменений: [Changelog](CHANGELOG.md).
